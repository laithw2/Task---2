Computer Networks: Introduction

A computer network is a collection of computing devices that are connected together to communicate and share resources. This overview covers key concepts from Chapter 1 of our textbook, "Computer Networking: A Top-Down Approach" by Kurose and Ross.

What is the Internet?

The Internet is a global network of networks that connects billions of devices worldwide. It can be viewed from two complementary perspectives:

"Nuts and Bolts" View: The Internet consists of:

  • End systems (hosts) - Computers, smartphones, and other devices at the "edge" of the network
  • Communication links - Physical media like fiber optic cables, copper wires, and radio waves
  • Packet switches - Routers and switches that forward data through the network
  • Protocols - Rules that control the sending and receiving of information

"Service" View: The Internet provides:

  • Infrastructure for distributed applications (web, email, video streaming, etc.)
  • Communication services for applications
  • Programming interfaces that applications can use to access these services

What is a Protocol?

A protocol defines the format and order of messages exchanged between two or more communicating entities, as well as the actions taken on the transmission and receipt of a message. Protocols are to computer networks what language is to human communication.

Just as humans use specific protocols for communication (like greetings, asking questions, and saying goodbye), computers use network protocols to establish connections, transfer data, and terminate connections.

Examples of Internet protocols include:

  • HTTP - For web browsing
  • SMTP - For email transmission
  • TCP - For reliable data transfer
  • IP - For routing packets across networks

Network Edge: Hosts and Access Networks

The network edge refers to the devices and connections at the "edge" of the network, including:

End Systems (Hosts)

These are the devices that run applications and connect to the Internet:

  • Personal computers, laptops, and workstations
  • Smartphones and tablets
  • IoT devices (Internet of Things)
  • Servers in data centers

Access Networks

These are the networks that connect end systems to the first router (edge router) on a path to any other distant end system:

Access Type Description Typical Speeds
Digital Subscriber Line (DSL) Uses existing telephone lines 24-52 Mbps downstream, 3.5-16 Mbps upstream
Cable Uses cable TV infrastructure (HFC) 40 Mbps - 1.2 Gbps downstream, 30-100 Mbps upstream
Fiber to the Home (FTTH) Direct fiber optic connection Up to 10+ Gbps (symmetrical)
Wireless (WiFi) Wireless local area network Up to 450+ Mbps (802.11n/ac/ax)
Cellular (4G/5G) Mobile cellular network 10-100+ Mbps (4G), 100 Mbps - 10 Gbps (5G)

Physical Media

Physical media are the physical materials that carry the signals in a computer network:

Guided Media:

  • Twisted Pair Copper Wire - Used in DSL and Ethernet
  • Coaxial Cable - Used in cable TV networks
  • Fiber Optic Cable - Uses light pulses, highest capacity

Unguided Media (Wireless):

  • Radio - WiFi, cellular networks
  • Microwave - Point-to-point links
  • Satellite - Global coverage

Network Core: Packet Switching vs. Circuit Switching

The network core is the mesh of packet switches and links that interconnects the Internet's end systems.

Packet Switching

In packet switching, data is divided into small packets that are sent independently through the network:

  1. Messages are broken into packets
  2. Packets travel independently through the network
  3. Each packet is forwarded from router to router
  4. Packets may take different paths and arrive out of order
  5. The receiving end system reassembles the packets into the original message

Key characteristics of packet switching:

  • Store-and-forward transmission - Each packet must be received completely before it can be transmitted to the next hop
  • Queuing delay and packet loss - Packets may have to wait in router buffers, and can be dropped if buffers overflow
  • Statistical multiplexing - Network resources are shared on demand

Circuit Switching

In circuit switching, resources are reserved for the duration of a communication session:

  1. A dedicated path is established before communication begins
  2. Resources are reserved along the entire path
  3. The connection provides guaranteed performance
  4. Resources remain allocated even when not in use

Circuit switching can be implemented using:

  • Frequency-Division Multiplexing (FDM) - The frequency spectrum is divided into bands
  • Time-Division Multiplexing (TDM) - Time is divided into slots

Packet switching is generally more efficient for data communication because it allows better sharing of network resources, especially for bursty traffic. Circuit switching provides guaranteed performance but can waste resources during idle periods.

Internet Structure and ISPs

The Internet is not a single network but a network of networks. Its structure includes:

  • Access ISPs - Connect end users to the Internet
  • Regional ISPs - Connect access ISPs within a region
  • Tier-1 ISPs - Global coverage, form the backbone of the Internet
  • Internet Exchange Points (IXPs) - Where ISPs connect to exchange traffic
  • Content Provider Networks - Private networks run by companies like Google, Facebook, and Microsoft

Performance: Delay, Loss, and Throughput

Network performance is measured using several key metrics:

Delay

Total delay in a network has four components:

  1. Processing delay - Time needed for a router to examine the packet header and determine where to direct it
  2. Queuing delay - Time a packet spends waiting in router buffers
  3. Transmission delay - Time needed to push all of the packet's bits into the link (L/R, where L is packet size and R is transmission rate)
  4. Propagation delay - Time for a bit to travel from one end of a link to the other (d/s, where d is distance and s is propagation speed)

Total nodal delay = Processing delay + Queuing delay + Transmission delay + Propagation delay

Packet Loss

Packet loss occurs when a packet arrives at a full buffer in a router and is dropped. This can happen during periods of network congestion. Lost packets may need to be retransmitted, affecting overall performance.

Throughput

Throughput is the rate at which bits are transferred between sender and receiver:

  • Instantaneous throughput - Rate at a given point in time
  • Average throughput - Rate over a longer period of time

The end-to-end throughput is often limited by the bottleneck link, which is the link with the minimum transmission rate along the path.

Protocol Layers

Networks are complex systems with many components. To manage this complexity, network functionality is organized into layers:

Internet Protocol Stack:

  1. Application Layer - Supports network applications (HTTP, SMTP, FTP)
  2. Transport Layer - Process-to-process data transfer (TCP, UDP)
  3. Network Layer - Routing of datagrams from source to destination (IP)
  4. Link Layer - Data transfer between neighboring network elements (Ethernet, WiFi)
  5. Physical Layer - Bits "on the wire" or "in the air"

Benefits of Layering:

  • Reduces complexity by breaking the network into manageable components
  • Allows for modular design and implementation
  • Makes it easier to update or replace individual components
  • Facilitates standardization of interfaces between layers

Network Security

Network security is a critical aspect of modern networks. Some key security concerns include:

  • Malware - Viruses, worms, spyware, and other malicious software
  • Denial of Service (DoS) - Overwhelming resources to make them unavailable
  • Packet Sniffing - Intercepting and reading packets on a network
  • IP Spoofing - Sending packets with a false source address

Security measures include encryption, authentication, firewalls, and intrusion detection systems.

The Internet was not originally designed with security in mind. Security features have been added over time, but security remains an ongoing challenge in network design and operation.
